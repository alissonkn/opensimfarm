OpenSimFarm

Plant, harvest, raise livestock and weather the seasons. The 1993 farm simulation, rebuilt from scratch for today's Windows and Linux.

Download How to install

Free and open source (GPL-3.0). Needs your own copy of SimFarm.

💾

Bring your own SimFarm

OpenSimFarm contains none of the original game's files: no pictures, sounds, music, maps or texts. It reads them, read-only, from your own SimFarm folder (the one with MEGADATA.IDX and MEGADATA.EEA). On the first start it looks for the folder itself, or you choose it once. Your saves from the original game load as they are.

What's inside

🌾

The whole farm

Fields and crops, orchards, livestock, machines and buildings, the weather, the market, the bank and the town around you.

💾

Your old saves

Loads and saves the original's saved games, so a farm from 1993 picks up where you left it.

🌪️

Disasters included

Tornadoes, windstorms, droughts, floods, locusts and frost, plus the crop duster, the county fair and the rodeo.

🔊

Modern Sound

Optional: the game's own sounds cleaned up and in stereo, and the music played with new instruments.

✨

Modern Render

Optional: the game's own pictures smoothed, and animals, machines and cars gliding from cell to cell.

🚜

Smart Driving

Optional: machines plan their way to the field and back over roads, gates and bridges. Any window size, from a laptop to a big screen.

Install

Pick your system. The files are on the releases below; the newest one is always at the top.

  1. Download OpenSimFarm-VERSION-windows-x64-setup.exe.
  2. Run it. It installs for your user only, so no administrator rights are needed.
  3. On the Your SimFarm folder page, check the folder it found, or click Browse and choose it.
  4. Start OpenSimFarm from the Start menu or the desktop shortcut.

The installer is not code-signed, so Windows SmartScreen may warn the first time: click More info, then Run anyway. Uninstalling (Settings → Apps) keeps your saves and settings.

  1. Download opensimfarm_VERSION-1_amd64.deb (Debian 12 or newer, Ubuntu 22.04 or newer).
  2. Install it, which also installs SDL2:
    sudo apt install ./opensimfarm_VERSION-1_amd64.deb
  3. Start OpenSimFarm from the menu, or run opensimfarm.

Remove it with sudo apt remove opensimfarm. Your saves stay in ~/.config/opensimfarm.

  1. Download opensimfarm-VERSION-1.x86_64.rpm.
  2. Install it, which also installs SDL2:
    sudo dnf install ./opensimfarm-VERSION-1.x86_64.rpm
    On openSUSE: sudo zypper install ./opensimfarm-VERSION-1.x86_64.rpm
  3. Start OpenSimFarm from the menu, or run opensimfarm.

Remove it with sudo dnf remove opensimfarm. Your saves stay in ~/.config/opensimfarm.

  1. Download OpenSimFarm-VERSION-windows-x64.zip and unzip it anywhere.
  2. Double-click opensimfarm.exe. If it doesn't find SimFarm by itself, it asks you to choose the folder once.

Handy for a USB stick or for trying it out. Settings and saves go to %APPDATA%\OpenSimFarm.

🧭 First start

OpenSimFarm searches the usual places for your SimFarm folder (your home folder, the drive roots on Windows, /opt, /media, …). If it can't find it, it asks you to choose it with the system's folder dialog. On Linux that dialog needs zenity or kdialog. The folder is remembered. If you move or delete it later, OpenSimFarm notices and asks for its new place.

Build it yourself

Play from source

You need CMake, a C++17 compiler and the SDL2 development package (libsdl2-dev or SDL2-devel).

git clone https://github.com/alissonkn/opensimfarm.git
cd opensimfarm/engine
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/opensimfarm /path/to/SimFarm

Make the installers

One script builds all of them on Linux, including the Windows installer (cross-compiled with Zig, packed with NSIS):

cd opensimfarm/engine
tools/package.sh          # or: windows / rpm / deb

The tools to install first and the details are in Building the installers.

Questions

Do I need the original game?

Yes. OpenSimFarm is a new program that plays with the files of your own copy of SimFarm, so the pictures, sounds and maps all come from it. Nothing of the original game is included or downloaded.

Is any of the original code in it?

No. The engine was written from scratch in C++17, from a description of how the game behaves and how its files are laid out.

Will it change my SimFarm files?

No. It only reads them. Settings and saved games go to your own settings folder: %APPDATA%\OpenSimFarm on Windows, ~/.config/opensimfarm on Linux.

Does it look and play like the original?

That's the aim: the same rules, screens and timing, checked side by side against the original. A few things are better on purpose (any window size, clearer messages, a full price list), and the Modern options are there if you want them, all switchable in the Options menu.

Something doesn't work. Where do I report it?

Open an issue on GitHub, with your system, the version and what happened.
