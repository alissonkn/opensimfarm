OpenSimFarm

Plant, harvest, raise livestock and weather the seasons. The 1993 farm simulation, rebuilt from scratch for Windows, Linux and your browser, even on a phone.

Bring your own SimFarm

OpenSimFarm includes none of the original game's files. It reads them from your own SimFarm folder (DOS or Windows, installed or straight from the CD), and your old saves load as they are. In the browser the files are read on your computer: nothing is uploaded.

How to install
  • Windows: run the installer (no administrator rights needed). If SmartScreen warns, click More info → Run anyway. Or unzip the zip and run opensimfarm.exe.
  • Debian / Ubuntu: sudo apt install ./opensimfarm_VERSION-1_amd64.deb
  • Fedora / openSUSE: sudo dnf install ./opensimfarm-VERSION-1.x86_64.rpm (or zypper install)
  • First start: it looks for your SimFarm folder by itself, or asks you to choose it once.

Older versions and the source code are on GitHub.

Questions

Do I need the original game?

Yes. OpenSimFarm plays with the files of your own copy of SimFarm, so the pictures, sounds and maps all come from it. Nothing of the original game is included or downloaded.

Is any of the original code in it?

No. The engine was written from scratch in C++, from a description of how the game behaves and how its files are laid out.

Does it play like the original?

That's the aim: the same rules and timing, checked side by side against the original. The extras are optional and can be switched off in the Options menu.

Where are my saves?

%APPDATA%\OpenSimFarm on Windows, ~/.config/opensimfarm on Linux. In the browser they stay in the browser: use Saves on the play page to download or upload them. Your SimFarm files are never changed.

Something doesn't work. Where do I report it?

Open an issue on GitHub, with your system, the version and what happened.
